# Cursor++ — maintained BYOK fork

Model protocols, provider management, search, usage statistics and compatibility fixes for Cursor.

This extension is maintained at [zhanglinrun/CCursor](https://github.com/zhanglinrun/CCursor), based on CometixSpace and Yoahoug's work under AGPL-3.0-or-later.

Use the repository's full installer for first installation and application patches. Installing this VSIX alone is insufficient. See the repository README for verification, Remote SSH limitations and update instructions.
